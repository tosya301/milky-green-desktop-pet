## macOS（Apple Silicon）实际运行

- 单元测试 100 项全部通过。
- 番茄钟语音：12 项。21 段语音都能解码；短休、长休、休息结束、整组完成各自到点触发正确的类别；暂停、重置、手动切换、重启恢复都不误报；收起时照常播报。
- 语音音量：8 项。滑杆样式与四个角色的面板布局、快速拖动、播放中实时调音量、退出重开后保存（包括 0 静音）、跨重启不重复轮换。
- 点击与切换：5 种角色视图的轻点回弹、眨眼、连点开心与表情恢复。
- 拖动规则：5 项。5 px 以内算点击，松手后不再跟随，新一次拖动重新计阈值，15 秒保护。
- 拖动跟手：常服每秒移动 117 次、95% 误差 2 px；奶小绿常服每秒 118 次、95% 误差 2 px（模拟光标与输入）。
- 嘴形同步：9 组（五种角色视图、选中表情、番茄钟收起、空闲时来语音）。开始动嘴比语音晚 7–48 ms，停嘴时刻在语音结束前 30 ms 到结束后 1 ms 之间，嘴形与语音响度轨道的相关系数 0.982–0.997；音量为 0 时不动嘴；多角色时只有当前角色说话；中途换角色由新角色说完；暂停时嘴与语音同时停止。
- 重启：运行中收起番茄钟后重开，后台照常计时并到点播报；可见的计时窗重开后照常显示；暂停或已完成的计时不会多开窗口。
- 恢复：立绘或番茄钟的页面进程被结束后自动重新载入，计时按原截止时间继续；GPU 进程被结束后，WebGL 角色在约 1.5 秒内重新绘制。
- 长时间使用：40 次切换角色、12 次全身/半身切换、200 次换表情、300 次调音量之后，窗口和进程数量不增加，没有错误。

## Windows x64 包体核验

- `MilkyGreenPet.exe` 为 x64 程序，版本信息为 0.1.0，内含 16–256 px 七档图标。
- `resources/app.asar` 解包后与构建时暂存的内容逐文件一致；与 Mac 版的应用内容逐文件相同，只多一份便携启动器用的 NSIS 许可。
- 便携 EXE 内嵌的程序与目录版逐文件一致；目录 ZIP 解压后也逐文件一致。
- 托盘图标在 100%、150%、200% 三种缩放下都有对应尺寸。
